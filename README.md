## 🚀 Run locally

Static site, no build step required:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

Or just serve the repo root with any static file server (e.g. `npx serve`).

## 📁 Structure

- `index.html` — main page (Vue 3 catalog)
- `404.html` — GitHub Pages 404 page with built-in RU/EN switch
- `robots.txt`, `sitemap.xml` — SEO (sitemap is auto-regenerated by `scripts/verify.py`)

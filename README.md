## 🚀 Run locally

Static site, no build step required:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

Or just serve the repo root with any static file server (e.g. `npx serve`).

## 📁 Structure

- `index.html` — main page (Vue 3 catalog)
- `films/<imdbId>/index.html` — a static SEO page per film/series (hybrid slug `<id>-<title-en-slug>`, fallback id `kp-<kpId>` when no imdbId); shares the main page's styles, language switch and theme toggle via `js/film.js`
- `404.html` — GitHub Pages 404 page with built-in RU/EN switch
- `js/common.js` — shared helpers (slug/URL builders, lang/theme resolution, rating formatting, error handler) used by `js/app.js` and `js/film.js`
- `robots.txt`, `sitemap.xml` — SEO (sitemap is auto-regenerated by `scripts/verify.py`; indexes home page + all film pages)
- `scripts/lib.py` — shared helpers for the scripts below
- `scripts/verify.py` — data/site integrity checker (source of truth, end with `✅ All good`; also checks generated pages are fresh)
- `scripts/gen_pages.py` — regenerates `films/*` pages from `js/data.js` + `js/i18n.js`
- `scripts/pw_kp.py` — Kinopoisk search + rating lookup via Playwright (kpId, kpRating)
- `scripts/show_types.py` — prints every catalog record with its source line number
